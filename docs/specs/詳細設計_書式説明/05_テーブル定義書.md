# テーブル定義書 記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
**1テーブル**の物理構造の定義。**永続化レコード（表構造）の正本**であり、データアクセス（Mapper）・サービスが参照する。

## 配置・ファイル名
`テーブル定義書/<論理名>_テーブル定義書.docx`（`<論理名>` は基本設計の論理名。物理名（小文字スネークケース）は本文・一覧表で定義する）。

## ヘッダー固有
- 機能グループ：`―`（複数機能で共有される横断定義）。
- 機能：`テーブル定義 / <論理名>`（2段落）。

## 本文の構成と書き方
- **テーブル基本情報**：論理名／物理名（snake）／備考。
- **テーブル構造**：No(自動採番) / 列論理名 / 列物理名（snake）/ 型定義 / NOT NULL / UNIQUE / 備考。
  - 型定義は**システム構成で指定したDB製品の物理型**で記す（方言に従う）。日付と日時を区別する。
  - **区分（列挙型）を持つ列は文字列コードで保持**し、備考に `※型定義書【...】を参照` を添える。
  - NOT NULL/UNIQUE はエンティティ定義書の必須欄・一意制約に従う。
- **テーブル制約**：No(自動採番) / 制約物理名 / 列物理名 / 制約定義 / 備考（主キー・一意・外部キー 等。制約物理名は snake。主キーは `<テーブル名>_pkey` 等、基本設計のDB物理設計標準に従う）。
- **インデックス**：索引物理名は `<テーブル名>_<列名>_idx` 等のスネークケース（基本設計のDB物理設計標準に従う）。無ければ `-`（凡例どおり）。

## 固有の決定事項
- 本様式が**永続化エンティティ型（`～Entity`）の構造の正本**。Mapper の出力やサービスの取得は `～Entity` を `※テーブル定義書【...】を参照` で結び、型情報に同一構造を**二重定義しない**。
- 列の論理名・型・桁・NULL可否はエンティティ定義書と整合させる。

## 記入例（抽象）
| 列論理名     | 列物理名      | 型定義              | NOT NULL | UNIQUE | 備考                            |
| ------------ | ------------- | ------------------- | -------- | ------ | ------------------------------- |
| ID           | id            | integer（自動採番） | Yes      | Yes    | 主キー                          |
| サンプル区分 | sample_status | varchar(20)         | Yes      |        | ※型定義書【サンプルステータス】を参照 |
| サンプル日付 | sample_date   | date                |          |        |                                 |
