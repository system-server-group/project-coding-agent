# DB/IF定義書 記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
**1テーブル専用**のデータアクセス（Mapper）を**メソッド単位**で定義する。DB との入出力（IO）を担う。

## 配置・ファイル名
`データアクセス定義書/データベース/<論理名>_DBIF定義書.docx`（`<論理名>` は対象表の論理名。クラス名（`～Mapper`）は本文・一覧表で定義する）。

## ヘッダー固有
- 機能グループ：対象表の所属グループ。
- 機能：`<Mapper論理名>`（単段落）。

## 本文の構成と書き方
- **DB/IF基本情報**：論理名／クラス名（`～Mapper`）／処理内容。
- **インターフェース一覧**（メソッドごとに以下のメソッド基本情報を繰り返す）：
  - 論理名／物理名（camelCase）／概要
  - 入力情報（論理）：受け取る条件・引数（型参照は `※型定義書【...】を参照`）。
  - 射影列：取得する列（対象表の全列／特定列）。
  - 結合対象/条件：結合が無ければ「なし」。
  - 選択条件：抽出条件を**物理列・論理条件**で記す（SQL文・`LIKE`/`LIMIT` を書かない。動的条件は「入力のある条件のみ適用」「条件皆無なら全件」等を明記）。
  - ソート条件：既定の並び順（昇順/降順、対象列）。
  - 出力表 or 型（物理名）：出力する永続化エンティティ型。`<テーブル物理名のPascalCase>Entity（※テーブル定義書【...】を参照）`。

## 固有の決定事項
- **1表専用**：他テーブルを操作しない。他表が必要ならその表専用の Mapper を用いる（参照側のサービスごとにメソッドを再生産しない）。
- 入出力は**永続化エンティティ型（`～Entity`）**であり、テーブル定義書を正本に参照する。**型情報に二重定義しない**（`～Entity` の構造正本はテーブル定義書）。
- 参照先や関連 Mapper が未作成（後続機能で定義）の場合は**前方参照**とし、「後続の〇〇機能で定義」と注記する。

## 記入例（抽象・メソッド基本情報）
| 項目            | 値                                                                    |
| --------------- | --------------------------------------------------------------------- |
| 論理名 / 物理名 | 条件検索 / search                                                     |
| 射影列          | samples テーブルの全列                                                |
| 選択条件        | 入力された条件を動的にAND結合（入力のある条件のみ適用、皆無なら全件） |
| ソート条件      | id の降順（既定）                                                     |
| 出力表 or 型    | SamplesEntity（※テーブル定義書【サンプルテーブル】を参照）            |
