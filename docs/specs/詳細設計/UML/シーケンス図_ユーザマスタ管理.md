# シーケンス図 ― ユーザマスタ管理（CSV編集）

CSVの行ごとの編集属性（追加/更新/削除）に従い処理。パスワードのハッシュ化はユーザ認証認可 システム共通仕様書に従う。部署IDは部署マスタ存在チェック。

```mermaid
sequenceDiagram
    actor A as システム管理者
    participant V as ユーザマスタ管理画面
    participant C as ユーザマスタ管理Ctrl
    participant S as ユーザマスタ管理Service
    participant UM as ユーザマスタマッパー
    participant DR as 部署参照Service
    participant DB as DB

    A->>V: CSVアップロード(先頭列=編集属性)
    V->>C: CSVアップロード(CSV)
    C->>S: 編集(CSV)
    S->>S: ファイル形式チェック / 入力値チェック
    S->>DR: 部署存在判定
    alt 入力値違反
        S-->>V: エラー表示(行番号別)
    else
        loop CSV各行(編集属性)
            alt ユーザの追加
                S->>S: 既存ID重複チェック / パスワードハッシュ化
                S->>UM: 追加
            else ユーザの更新
                S->>S: 存在チェック / 排他チェック / パスワード非ブランクならハッシュ
                S->>UM: 更新
            else ユーザの削除
                S->>S: 自己削除禁止 / 存在チェック / 排他チェック
                S->>UM: 削除
            else 何もしない
                S->>S: スキップ
            end
        end
        alt 業務エラー
            S-->>V: 「{行}行目で異常終了しました」 / ロールバック
        else
            UM->>DB: コミット
            S-->>V: 全件一覧表示
        end
    end
```

> 横断参照「ユーザ参照」（ユーザ名取得）は本グループに定義。排他「他のユーザが更新中」は、存在確認の後に実行した更新・削除の件数が0件であること（確認から実行までの間に他の処理が当該レコードを変更・削除した競合）で判定する（案件更新の更新日時照合とは異なる方式）。
