# ER図

基本設計（`docs/specs/基本設計/エンティティ/ER図.md`）を流用・更新。論理名で表記し、物理テーブル名・列・型はテーブル定義書で確定する。

- 案件情報 (E01) 1 ─ 0..5 案件情報添付ファイル (E02)（添付は1案件に0〜5件）
- 会社マスタ・ユーザマスタ・部署マスタは独立マスタ。ユーザの部署ID・案件の取引先・登録者/登録部署は**論理参照（DB外部キーではない）**。

```mermaid
erDiagram
    E01 ||--o{ E02 : "0..5"

    E01[案件情報]{
        整数 管理コード PK
        文字列 件名
        区分 ステータス
        文字列 取引先
        文字列 商流
        文字列 案件概要
        文字列 工程
        日付 開始日
        日付 終了日
        文字列 スキル
        文字列 人数
        文字列 残数
        区分 BP募集要否
        文字列 BP募集詳細
        文字列 作業場所
        文字列 見込単価
        区分 契約種別
        文字列 備考
        文字列 登録者
        文字列 登録部署
        日時 登録日時
        文字列 更新者
        文字列 更新部署
        日時 更新日時
    }
    E02[案件情報添付ファイル]{
        整数 ファイルID PK
        整数 管理コード FK
        文字列 ファイル名
        バイナリ 実ファイル
        整数 ファイル容量
        文字列 登録者
        文字列 登録部署
        日時 登録日時
    }
    E03[会社マスタレコード]{
        整数 会社ID PK
        文字列 会社名
    }
    E04[ユーザマスタレコード]{
        文字列 ユーザID PK
        文字列 ユーザ名
        文字列 メールアドレス
        整数 部署ID
        区分 ロール
        文字列 パスワード
    }
    E05[部署マスタレコード]{
        整数 部署ID PK
        文字列 部署名
    }
```

> 注: 取引先（案件情報）は会社マスタ外の名称も許容。ユーザの部署ID は登録時点で部署マスタに存在するが DB 外部キーではない（部署削除による不整合は参照側機能で処理）。登録者/登録部署/更新者/更新部署はユーザ・部署マスタの変更・削除の影響を受けない記録値。
