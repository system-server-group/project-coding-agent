# シーケンス図 ― 案件情報更新

URLの管理コードで表示し、編集確定で更新。読込〜更新間に他ユーザが更新した場合は排他制御で中止。添付の追加/DL/削除、メール送信を含む。

```mermaid
sequenceDiagram
    actor U as ユーザ
    participant V as 案件情報更新画面
    participant C as 案件情報更新Ctrl
    participant A as 添付ファイルAPI
    participant S as 案件更新Service
    participant PM as 案件情報マッパー
    participant FM as 案件情報添付ファイルマッパー
    participant M as 営業情報メール送信Service
    participant E as エラー画面

    U->>V: 画面アクセス(URLに管理コード)
    V->>C: 更新画面表示(管理コード)
    alt 管理コード未指定
        C-->>E: ページ未検出
    else
        C->>S: 案件取得(管理コード)
        S->>PM: 案件取得
        S-->>C: 案件
        C-->>V: 表示(編集保護オン)
        V->>A: 添付一覧取得(管理コード)
        A->>S: 添付一覧取得(管理コード)
        S->>FM: 添付一覧取得(実ファイルを除く)
        S-->>A: 添付一覧
        A-->>V: 添付一覧
        V->>V: 【ファイル一覧】を描画
    end
    opt 添付ダウンロード(編集保護オン・【ファイル一覧】の行クリック)
        V->>A: 添付ダウンロード(ファイルID)
        A->>S: 添付ダウンロード(ファイルID)
        S->>FM: 添付取得(実ファイルを含む)
        S-->>A: 添付ファイル
        A-->>V: ダウンロード応答
    end
    U->>V: 編集保護解除
    opt 添付削除(編集保護オフ・行クリック → 【削除確認ダイアログ】でOK)
        V->>A: 添付削除(ファイルID)
        A->>S: 添付削除(ファイルID)
        S->>FM: 添付を削除
        S-->>A: 削除件数
        A-->>V: 削除結果
        V->>V: 【ファイル一覧】を再描画
    end
    U->>V: 編集 / 添付指定 / 編集確定
    V->>V: 入力値チェック
    V->>C: 案件更新(案件更新Form)
    C->>S: 案件更新(案件更新Form)
    S->>S: ユーザ名・部署名取得 / 排他チェック(読込〜更新間の他者更新)
    alt 排他競合
        S-->>C: 中止(ロールバック)
        C-->>V: 「他のユーザが案件情報を更新しました」表示
    else
        S->>PM: 案件情報を更新(更新者/更新部署/更新日時)
        opt 添付指定あり
            S->>FM: 添付を登録
        end
        alt メール送信ON
            S->>M: メール送信(件名「【営業情報】(更新) {件名}」, 本文)
        end
        S-->>C: 完了
        C-->>V: 同画面で最新表示
    end
```

> 添付ファイルの一覧取得・ダウンロード・削除は【添付ファイルAPI】で確定済み。排他制御の方式は基本設計に未記載のため詳細設計で確定した（案件情報の更新日時を読込時の値と照合する楽観排他。専用のバージョン列は設けない）。登録者・登録日時は更新対象に含めない。
