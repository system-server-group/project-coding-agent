# サービス一覧表（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
業務処理系サービスの索引。**機能グループ**ごとにグルーピングする。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`業務処理系 サービス一覧表`（単段落）。
- 本文見出しは**機能グループ名**でグルーピングする。

## 本文の構成と書き方
- 機能グループ見出しの下に表：No(自動採番) / 論理名 / 物理名（`～Service`）/ 概要。

## 固有の決定事項
- 個別の**サービス定義書と 1:1** で対応させる。
