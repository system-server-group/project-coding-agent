### 判定区分の定義

- **一致**: 主張の値がデータ正本の実測値と一致する。
- **実行時生成**: テスト実行時に作られる想定の値（案件情報の件数・管理コード 1001・添付ファイルの生成物・HTTPステータス・入力文字列・メール通数など）。データ正本に対応物が無いのが正常であるため【不一致】には入れない。
- **対応物なし**: データ正本ではなく画面部品の仕様値・証跡採取の規定・アプリ設定値・別仕様書に由来する値。同上の理由で【不一致】には入れない。
- **不一致**: 主張の値がデータ正本の実測値と食い違う。

- 参照テストデータ欄が空欄のケース: 5-2 / 6-1 / 6-2 / 6-3 / 7-1（いずれも前提条件が「・未認証」）。
- `00_共通部品/data/` の5ファイル、`_baseline/data/` の3ファイルは、いずれも仕様書のどれかのケースの参照テストデータ欄に現れる。facts が挙げる8ファイルと、仕様書に現れるパス8種は集合として一致する。
