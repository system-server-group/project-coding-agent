# モデル型定義書 記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
モデル型（DTO・ドメインモデル）**1件**の定義。アプリが参照する**ドメイン型**を表す。

## 配置・ファイル名
`型情報定義書/モデル型/<論理名>_モデル型定義書.docx`（凡例に合わせ `モデル型/` 配下。`<論理名>` は基本設計の論理名。物理名（PascalCase）は本文・一覧表で定義する）。

## ヘッダー固有
- 機能グループ：`―`（複数機能で共有される横断型）。
- 機能：`型情報定義 / <論理名>`（2段落）。
- 文書種別名：`型情報定義書 モデル型`。

## 本文の構成と書き方
- **型定義基本情報**：種別＝`モデル型(DTO)`／論理名／物理名（PascalCase）／概要。
- **型定義詳細仕様**：No(自動採番) / 項目論理名 / 項目物理名（camelCase）/ 型。
  - 型は基本型・他モデル型・列挙型を物理名で記す。繰り返しは `型[]`。
  - 他のプロジェクト固有型を参照する場合の注記方法は共通規範の参照記法に従う。

## 固有の決定事項
- **ドメイン型のみを定義する**。永続化レコード（永続化エンティティ型 `～Entity`）をモデル型として二重定義しない（`～Entity` の構造はテーブル定義書が正本）。
- 区分項目は、**列挙型**で持つ。永続化レコードでは文字列コードで持ち、レコード⇄ドメインの変換はサービス層が行う（本書はドメイン側＝列挙型で記す）。

## 記入例（抽象）
| 項目論理名           | 項目物理名   | 型           |
| -------------------- | ------------ | ------------ |
| サンプル文字項目     | sampleString | string       |
| サンプル区分項目     | sampleStatus | SampleStatus |
| サンプル繰り返し項目 | sampleList   | SampleItem[] |
