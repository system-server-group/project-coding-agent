# テーブル定義書一覧表（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
テーブル（永続化レコード）の索引。物理名の実体一覧の正本。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`テーブル定義一覧表`（単段落）。

## 本文の構成と書き方
- **テーブル定義一覧表**：No(自動採番) / 論理名 / 物理名 / 概要。
  - 物理名は DB識別子（小文字スネークケース）。`Entity` 等の接尾辞を付けない（凡例にそのような流用例があれば成果物で正す）。

## 固有の決定事項
- 個別の**テーブル定義書と 1:1** で対応させる。
- テーブル定義書が表構造（永続化レコード）の正本であり、ここはその索引。
