### 判定区分の定義

- **一致**: 主張の値がデータ正本の実測値と一致する。
- **実行時生成**: テスト実行時に作られる／実行時にブラウザ上で観測される値（DOM 要素の件数など）。データ正本に対応物が無いのが正常であるため【不一致】には入れない。
- **不一致**: 主張の値がデータ正本の実測値と食い違う。

## 補足（転記のみ・判断は含まない）

- ケース総数は仕様書シート「テストケース」から機械抽出して **7件**。内訳: 1-x=4（1-1・1-2・1-3・1-4）／2-x=3（2-1・2-2・2-3）。

- 仕様書に現れるパス3種は、facts が挙げる9ファイルのうち3ファイル（`_baseline/data/users.csv`／`_baseline/data/departments.csv`／`01_共通レイアウト/data/部署未登録ユーザ.csv`）と集合として一致する。残る6ファイル（`_baseline/data/companies.csv`・`00_共通部品/data/` の5ファイル）は本仕様書のいずれのケースの参照テストデータ欄にも現れない。
- ケース 1-1・1-2・2-1・2-2 の前提条件に現れる `営業部` は `_baseline/data/departments.csv` の 2行目（`1,営業部`）の値であるが、これら4ケースの参照テストデータ欄に記載されたパスは `_baseline/data/users.csv` のみである（`_baseline/data/departments.csv` は 1-3 の参照テストデータ欄にのみ記載されている）。以上は欄の記載内容の転記であり、判定は行っていない。
- `01_共通レイアウト/data/部署未登録ユーザ.csv` の password 列の値は `_baseline/data/users.csv` の SM0001 行の password 列の値と完全一致する（機械比較 True）。ケース 1-3 の操作手順は「パスワードに該当ユーザのパスワードを入力し」と記載しており、パスワードの平文値は仕様書に記載されていない（転記）。
- 期待する結果に現れる文字列リテラル（「営業情報管理システム」「404 Not Found」「ページが見つかりませんでした。」「403 Forbidden」「ページにアクセスできません。」「An Error Occurred」「エラーが発生しました。」「RELOAD」「TOINDEX」「案件情報一覧画面」）および URL（`/no-such-page`・`/master/departments`・`/projects`・`/`）は、データ正本ではなく設計文書由来の値であるため本報告の突合対象に含めていない（設計文書との突合は `突合報告_設計.md` が担う）。
