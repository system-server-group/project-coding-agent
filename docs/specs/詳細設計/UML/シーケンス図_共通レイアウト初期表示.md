# シーケンス図 ― 共通レイアウト 初期表示

共通レイアウトを持つ各画面の初期表示。ログイン中ユーザのユーザ名・部署名・ロールを取得し、ロールでナビ（マスタ管理系）を出し分ける。部署ID未登録時はサーバー内部エラー。

```mermaid
sequenceDiagram
    actor U as ユーザ
    participant V as 共通レイアウト適用画面
    participant C as 共通レイアウトCtrl
    participant A as ログイン情報
    participant UR as ユーザ参照Service
    participant DR as 部署参照Service
    participant E as エラー画面

    U->>V: 画面アクセス(パーマリンク)
    V->>C: 初期表示
    C->>A: ログイン中ユーザ・ロール取得
    A-->>C: ユーザID, ロール
    C->>UR: ユーザ名取得
    UR-->>C: ユーザ名
    C->>UR: 部署ID取得
    UR-->>C: 部署ID
    C->>DR: 部署名取得(部署ID)
    alt 部署ID未登録
        DR-->>C: 該当なし
        C-->>E: サーバー内部エラー
    else
        DR-->>C: 部署名
        C-->>V: ユーザ名・部署名表示 / ロールでナビ出し分け
    end
```

> 一般ユーザには会社/ユーザ/部署マスタのナビを非表示。ユーザ名・部署名取得は横断参照リソース（マスタ管理所属）を利用する。ログイン情報（ログイン中ユーザ・ロール）はフレームワーク側で管理される。
