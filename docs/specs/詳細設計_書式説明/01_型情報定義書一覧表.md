# 型情報定義書一覧表（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
システム全体のドメイン型の索引。内部に **3つの小表**を持つ：「基本型情報」「モデル型定義一覧表」「列挙型定義一覧表」。物理名の実体一覧の正本。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`型情報定義一覧表`（単段落）。

## 本文の構成と書き方
| 小表 | 列 | 書き方 |
|---|---|---|
| 基本型情報 | No / 論理名 / 物理名 / 概要 | 基本型語彙の正本。プロジェクトで固定的に保持する基本型（文字型・整数型・日付型・日時型・真理値・ファイル型 等）。安易に増減しない。 |
| モデル型定義一覧表 | No / 論理名 / 物理名 / 概要 | モデル型（DTO・ドメインモデル）を登録。物理名は PascalCase。 |
| 列挙型定義一覧表 | No / 論理名 / 物理名 / 概要 | 列挙型（状態区分・定数集合）を登録。物理名は PascalCase。 |

## 固有の決定事項
- 個別の**モデル型定義書／列挙型定義書と 1:1** で対応させる。
- **永続化レコード（テーブル構造）の型はここに登録しない**。テーブル定義書が表構造の正本であり、型情報に同一構造を二重定義しない。型情報に載せるのは**ドメイン型**（モデル型／列挙型）のみ。
- 凡例のサンプル行（`サンプル型` 等）は転記しない。

## 記入例（抽象）
- モデル型：`サンプル型定義 / SampleType / 〇〇を表すモデル型`
- 列挙型：`サンプル区分 / SampleStatus / 〇〇の状態を表す区分`
