## 3. 横断仕様の扱い（利用者裁定 2026-09-29）

本実施単位の対象は 21_会社マスタ管理 のみで、横断仕様のオーナー機能（既定 `00_共通部品`）は含まれない。会社マスタ管理画面に適用されるが会社マスタ管理の設計書群の外で定義された振舞いの扱いを利用者に確認し、次の裁定を得た。

- a) 画面部品仕様「ページネーション」の出力仕様、b) CSV共通仕様の囲み文字・読み取り規則・読み取り失敗・ラウンドトリップ、c) 入力値チェック共通仕様の使用文字（全角）の文字範囲の境界、d) ユーザ認証認可・パーマリンクの未ログイン時の保留と復帰・CSRF トークン不一致・失効時間 → **本実施単位では扱わない**。棚卸し表に「対象外（利用者裁定）」として記録する。
- e) 共通レイアウトの会社マスタボタン（遷移・強調表示・一般ユーザでの非表示）→ 21_会社マスタ管理 でケース化する。
- 会社マスタ管理の設計書が直接定める振舞い（セッション切れ時の挙動、一般ユーザの権限不足、形式チェック・入力値チェック、ページ送り・表示件数など）は 21_会社マスタ管理 でケース化する。横断仕様の文言（入力値チェックのメッセージ・エラー画面の表示内容）はオラクルとして用いる。
