# 詳細設計 UML

営業情報管理システムの詳細設計を補助する UML 図（Mermaid 記法）。
基本設計書（`docs/specs/基本設計/`）と詳細設計の記載規範（`docs/specs/詳細設計_書式説明/`）に基づき、システム全体の構造・振る舞いを俯瞰するために配置する。

## 表記の前提

- **クラス名・メソッド名・列挙コードは論理名で表記**する。物理名（`～Entity` / `～Mapper` / `～Service` / `～Ctrl` / `～Form` / `～Dto` 等の確定名、列挙定数コード）は、型情報定義書・テーブル定義書・各定義書で確定する。
- レイヤは **画面/APIコントローラー → サービス → データアクセス（Mapper：1表専用）**（`詳細設計_書式説明/00_共通規範.md`）。
- 横断参照（会社名・部署名・ユーザ参照）は**リソース指向**でマスタ管理側に 1:1 定義し、参照元機能ごとに増やさない。
- 本 UML は俯瞰図である。物理名・パーマリンク・画面テンプレートの正本は各定義書と一覧表（`詳細設計/イベント定義書/`・`詳細設計/画面定義/`・`詳細設計/テーブル定義書/`・`詳細設計/型情報定義書/`）であり、図と食い違う場合は各定義書を優先する。
