# 画面テンプレート一覧（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
画面（テンプレート＝View の実体、HTML 等）の物理定義の索引。**機能ごと**にグルーピングする。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`画面テンプレート一覧`（単段落）。

## 本文の構成と書き方
- セクション見出し「画面テンプレート一覧」の下に、**機能名の見出し**ごとに表を置く。
- 表：No(自動採番) / 画面名 / テンプレート（HTML）/ 備考。
  - 画面名は基本設計の画面レイアウト名と一致させる。
  - テンプレートは配置パス（例 `templates/<グループ>/<画面>.html`）。

## 固有の決定事項
- 個別の画面はここを**正本**とし、画面エンドポイント定義書（画面コントローラー）からは `※画面テンプレート一覧【<画面名>】を参照` で結ぶ。
- 機能が1つでも、サンプルの余剰機能群（見出し＋表）は削除し、対象機能分のみ残す。

## 記入例（抽象）

|---|---|---|---|
