# クラス図 ― マスタ管理（会社／ユーザ／部署）＋ 横断参照リソース（会社名／ユーザ／部署）

論理名で表記（物理名は各定義書で確定）。会社・ユーザ・部署の各マスタは管理画面（CSV）と、リソース指向の**横断参照サービス**（他機能が名称取得・存在チェックに利用）を 1:1 で持つ。CSV による更新方式は、会社・部署が洗い替え（全件削除して再登録）、ユーザが編集（行ごとの追加・更新・削除）である。マスタ管理画面はシステム管理者のみアクセス可。


> 補足: 横断参照サービス（会社名/ユーザ/部署）は基本設計に提供側の明示定義がない（利用要求のみ）ため、リソース指向でマスタ管理側に定義した（サービス一覧表・各サービス定義書で確定済み）。部署マスタの削除・部署ID変更時の整合チェックは部署側では行わず、参照側（共通レイアウト初期表示・案件登録等）で処理する。また、会社・部署は専用の CSV データ構造を持たない（ユーザのみ ユーザマスタCSVレコード を持つ）。CSV の様式（囲み文字・エスケープ）と読み取り方式の正本は CSV共通仕様 システム共通仕様書。
