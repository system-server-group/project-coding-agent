### 対応欄の表記規約

| 表記 | 意味 |
| --- | --- |
| `#n` | 棚卸し行 #n の文言が当該記述に対応する |
| `#n・#m` | 当該記述が複数行に分割して収録されている |
| `#n〜#m` | 当該記述が複数行の総則にあたる |
| `#n（欄外）` | 当該記述は棚卸し行 #n と同じ表行／同じ段落に属するが、**#n の文言には当該記述の内容が現れない**。末尾の補足節に再掲する |
| `#n（参照）` | 他文書・他節への参照指示。行 #n の導出根拠として関係する |
| `—（対応行なし）` | 文言が対応する棚卸し行が見つからない |
