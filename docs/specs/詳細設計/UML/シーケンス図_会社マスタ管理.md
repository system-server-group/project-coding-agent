# シーケンス図 ― 会社マスタ管理（CSV洗い替え）

全件ダウンロードと、CSVアップロードによる洗い替え（全件削除→登録）。会社マスタは案件情報の取引先オートコンプリート候補として参照されるが、取引先は会社マスタ外の名称も許容されるため、洗い替えによる参照側の不整合は生じない。システム管理者のみ。

```mermaid
sequenceDiagram
    actor A as システム管理者
    participant V as 会社マスタ管理画面
    participant C as 会社マスタ管理画面コントローラー
    participant S as 会社マスタ管理サービス
    participant CM as 会社マスタマッパー
    participant DB as DB

    rect rgb(245,245,245)
    Note over A,DB: ダウンロード
    A->>V: CSVダウンロード
    V->>C: CSVダウンロード
    C->>S: 全件取得
    S->>CM: 全件取得
    CM->>DB: 会社マスタ取得
    C->>S: CSV変換(並び替え済み一覧)
    S-->>V: CSV(会社マスタ.csv)
    end

    rect rgb(245,245,245)
    Note over A,DB: 洗い替え(アップロード)
    A->>V: CSVアップロード / ファイル選択
    V->>C: CSVアップロード(CSV)
    C->>S: 洗い替え(CSV)
    S->>S: ファイル形式チェック / 入力値チェック(必須・整数・一意・全角50)
    alt 違反あり
        S-->>V: エラー表示(行番号別)
    else
        S->>CM: 全件削除 → 全件登録
        CM->>DB: 削除 / 登録(トランザクション)
        Note over S: 取引先は会社マスタ外の名称も許容するため参照不整合の検査は行わない
        alt 失敗
            S-->>V: 実施前状態へ復元 → エラー画面(サーバー内部)
        else
            S-->>V: 全件一覧表示
        end
    end
    end
```

> 横断参照「会社名参照」（会社名一覧取得）は本グループに定義され、案件情報の一覧・登録・更新が取引先候補として利用する。会社マスタ管理サービスとは**別クラスとして併存**し、本機能の追加による変更は受けない。
> 会社マスタはレコードが0件になり得る（0件時のCSVはヘッダー行のみ、画面は「該当するデータがありません」を表示）。部署マスタのような0件化の除外条件は持たない。
