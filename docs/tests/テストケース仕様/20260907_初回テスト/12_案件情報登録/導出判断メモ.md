# 12_案件情報登録 導出判断メモ

> 本メモは生成時点の導出記録である（承認後は書き換えない。承認後の人手変更の正史は実施単位直下の `ケース変更台帳.md` が担う）。

## 位置づけ

案件情報登録画面は、案件情報の新規登録・添付ファイル1件の登録・営業情報メールの任意送信を行う画面。
本機能は**画面項目と初期値・メール送信切替・添付ファイルの形式チェック・入力値チェック（15項目）・
登録内容（登録者／登録部署／登録日時等の導出）・登録の異常分岐**を受け持つ。

横断仕様に由来する一般挙動（テキスト／テキストエリア／セレクトボックス／カレンダー／
オートコンプリート／ファイルピッカーの各部品、営業情報メールの様式、認証認可、パーマリンク）は、
オーナー機能 `00_共通部品` のケースへ横断参照で閉じる。

## 表示精度に関する注記（整合チェッカー C7 の警告について）

画面部品仕様「ファイルサイズの表示」は「四捨五入した結果の小数部が0となる場合は、小数部を
省略して整数で表示する」と定める。整合チェッカーの既定表示整形は小数第一位まで出す（`6.0MB`）ため、
6MB ちょうどの添付ファイルに言及するケース（2-2・2-4・2-7・2-8）のサイズ表記は
**値は一致し表示精度のみ既定と異なる**警告になる。設計の表示規則が正であり、本文は
設計どおりに記入している（`00_共通部品` の同種の注記と同じ扱い）。
