## 突合の規則

- 行番号: CSV行番号はヘッダー行を含む行番号（4桁0埋め、5桁以上はそのまま）。データ行番号はヘッダー行を除く行番号。
- 並び順: 会社名はコードポイント順、会社IDは数値順で実物の値を並べた結果と比べた。
- ページ: 実物の行を会社ID昇順に並べて、表示件数ごとに先頭から区切った範囲と比べた。ページ数は ceil(件数 ÷ 表示件数)、「全て」は1ページとした。
- 文字数: Unicode コードポイント数で数えた。サロゲートペアを含む値には UTF-16 の単位数も併記した。
- 入力値違反の機械判定（エラーメッセージの主張の突合用）: 仕様書本文の文言（必須・整数・1以上・2147483647以下・一意・50文字以内・使用不可能な文字）を、次の判定で近似した。
  - 会社ID: 空 → required、半角の `-?[0-9]+` に一致しない → integer、1 未満 → min、2147483647 超 → max、同じ文字列が前の行に既出 → unique
  - 会社名: 空 → required、コードポイント数が 50 超 → maxlen、U+0000〜U+007F または U+FF61〜U+FF9F の文字を含む → charset
  - 個々のメッセージの主張は、CSV行番号が上記の定義どおりで、かつメッセージ文言に対応する違反種別がそのセルの判定結果に含まれるとき「一致」とした。「これ以外のメッセージは表示されない」「データn行目についてのメッセージは表示されない」は、違反と判定されたセルの集合が列挙メッセージのセルの集合と同じとき「一致」とした。
  - 1つのセルに複数の違反種別が出た場合（7-2 の生成ファイル、8-10、8-11 のデータ9999行目）は、判定された全種別を実測値に併記した。どの種別のメッセージが表示されるかは突合の対象にしていない。
- 「対応先なし」: 主張の値の出典になるファイルが、そのケースの参照テストデータ欄に無いもの。参照欄の外にある実物で測った値は、実測値欄に「参考」として併記した。
- 件数の数え方: 同じ文言の主張（前提条件のユーザ・ベースライン4件、期待する結果の「ベースラインの4件のまま」など）も、ケースごとに1件と数えた。参照テストデータ欄のパスの実在は、ケースごとに欄内の全パスをまとめて1件とした。
