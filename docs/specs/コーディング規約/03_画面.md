# 画面（一覧・グリッド）の実装規範

> 共通規範は [00_実装共通規範.md](00_実装共通規範.md) を参照。本書は画面層の実装固有の事項を記す。
> 設計書（画面イベント・画面コントローラー・画面テンプレート一覧）の記載規範は、各様式の記載規範を参照。

## 技術スタック
- サーバ描画は **Thymeleaf**。テンプレートは `templates/<グループ>/<画面>.html`。
- スタイル・部品は **Bootstrap**（webjar）、一覧テーブルは **ag-grid**（webjar）。
  - webjar 参照は `@{/webjars/<lib>/...}`（`webjars-locator-lite` によりバージョン非依存パス）。
  - 画面固有 CSS/JS は `static/css/<画面>.css`・`static/js/<画面>.js` に置く。

## 画面コントローラー
- 画面コントローラー（`~Controller`）は**テンプレート名を返すのみ**。データ取得・業務ロジックは持たない。
- 一覧データや選択肢は、画面ロード後にクライアント JS が **REST API**（`/api/**`）から取得する。

## クライアント状態（ローカルストレージ）
- 一覧のテーブルレイアウト（列順・列幅・列固定・ソート・表示件数）と検索条件は
  **ブラウザのローカルストレージ**で保持する。状態保持用のサーバ API／セッションを派生させない。
- 初期表示：保存済みがあれば復元、無ければ既定（例：一覧は管理コード降順・表示30件、検索条件は既定値）。
- 検索成功時に検索条件を保存。テーブル初期化で保存内容を破棄し既定へ戻す。

## 区分（列挙型）の表示
- 区分は API が `{code,label}` で返す（[01_区分・列挙型.md](01_区分・列挙型.md)）。**表示は `label`** を用い、
  画面側にコード→ラベルの対応表を**持たない**。

## オートコンプリート（名称マスタ）
- 登録者・登録部署・取引先などマスタ由来の候補は、名称マスタ取得 API（種別ごとに
  `/api/master/user-names`・`/api/master/department-names`・`/api/master/company-names`）から取得して
  `datalist` 等に流し込む。候補値を画面に直書きしない。

## 認証・CSRF
- 画面・API は認証必須（ログイン画面・エラー画面を除く）。
- 認証付き POST（検索など）では、テンプレートが出力する CSRF メタ（`_csrf` / `_csrf_header`）を
  JS が読み取り、リクエストヘッダに付与する。

## CSV 出力
- 出力列・列順は表示中テーブルに従い、ソート順も表示に合わせる。
- ファイルの設定・囲み文字の適用・読み取り方式は「CSV共通仕様 システム共通仕様書」（正本）に従う
  （UTF-8 BOM 付き・CR+LF・区切りはカンマ。囲み文字はカンマ・ダブルクォート・改行を含む値のみに適用し、
  内部のダブルクォートは 2 つ重ねてエスケープ）。
