# コントローラー一覧表（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
コントローラーの索引。**画面系コントローラー一覧表**と **API一覧表**の2表を持ち、API定義書・画面コントローラー定義書の両方を束ねる。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`コントローラー一覧表`（単段落）。

## 本文の構成と書き方
- **画面系コントローラー一覧表** / **API一覧表**：各 No(自動採番) / 論理名 / 物理名（`～Ctrl`）/ ベースパス / 概要。
  - 画面系のベースパスは `/...`（`/api` を付けない）、API系は `/api/...`。
  - 種別はベースパスのプレフィックスで判別（`/api/**`＝API、それ以外＝画面）。

## 固有の決定事項
- 個別の**コントローラー定義書（API定義書／画面コントローラー定義書）と 1:1** で対応させる。
- ここに載せるのはコントローラー（クラス）単位。エンドポイント単位の「パス設定」は各定義書側で持つ。

## 記入例（抽象）
- 画面系：`サンプル画面コントローラー / SampleCtrl / /sample / 〇〇画面を表示する`
- API系：`サンプルAPIコントローラー / SampleApiCtrl / /api/sample / 〇〇のAPI`
