# 02_エラー 導出判断メモ

## 位置づけ

エラー画面は画面一覧に載る画面であり、独自の画面レイアウト・画面コントローラー定義書・画面イベント
定義書（再読込・ホーム遷移）を持つ。本機能は**エラー種別ごとの表示内容と、エラー画面上の2つの
イベント（再読込・ホーム遷移）**を受け持つ。

エラー画面への**到達条件そのもの**（未認証アクセス・権限不足・API のステータス使い分け）は
横断仕様（ユーザ認証認可・パーマリンク・API共通仕様）に由来するため、オーナー機能 `00_共通部品`
のケースが受ける。本機能は到達後の**画面の表示内容とイベント**に限る。

## 導出元

- 基本設計/画面レイアウト: エラー画面_画面レイアウト
- 詳細設計/画面コントローラー定義書: エラー画面_画面コントローラー定義書
- 詳細設計/画面イベント定義書: エラー画面_再読込／エラー画面_ホーム遷移
- 補完: パーマリンク システム共通仕様書、ユーザ認証認可 システム共通仕様書
