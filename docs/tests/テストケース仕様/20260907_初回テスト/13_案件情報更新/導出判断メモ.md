# 13_案件情報更新 導出判断メモ

> 本メモは生成時点の導出記録である（承認後は書き換えない。承認後の人手変更の正史は実施単位直下の `ケース変更台帳.md` が担う）。

## 位置づけ

案件情報更新画面は、URLで指定された管理コードの案件情報の閲覧・更新、添付ファイル一覧の表示・
ダウンロード・削除、営業情報メールの任意送信を行う画面。**編集保護**による入力可否の切替と、
**楽観排他による更新失敗**、**添付ファイルの5件上限**が本機能に固有の導出単位である。

横断仕様に由来する一般挙動（各画面部品、営業情報メールの様式、API共通仕様、認証認可、
パーマリンク）は、オーナー機能 `00_共通部品` のケースへ横断参照で閉じる。
入力値チェックの30ルールは `12_案件情報登録` と同一だが、**画面が異なれば適用も別の導出単位**で
あるため本機能でもケース化する（同じ画面部品の一般挙動ではなく、当画面の入力値チェックの適用である）。

## 表示精度に関する注記（整合チェッカー C7 の警告について）

6MB ちょうどの添付ファイルに言及するケースのサイズ表記は、設計の表示規則
（小数部が0なら整数で表示）に従い「6MB」と書く。整合チェッカーの既定表示整形は `6.0MB` を出すため
**値は一致し表示精度のみ既定と異なる**警告になる（`00_共通部品`・`12_案件情報登録` と同じ扱い）。
