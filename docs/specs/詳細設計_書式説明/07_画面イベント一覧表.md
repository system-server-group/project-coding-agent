# 画面イベント一覧表（索引）記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
画面イベント（画面の操作・契機）の索引。**機能グループ**ごとにグルーピングする。

## ヘッダー固有
- 機能グループ：`―`（システム全体の横断索引）。
- 機能：`画面イベント一覧表`（単段落）。
- 本文内の見出しは**機能グループ名**でグルーピングする（ヘッダーの機能グループ欄＝索引なので `―` とは別。本文見出しで分類する）。

## 本文の構成と書き方
- 機能グループ見出しの下に表：No(自動採番) / 論理名 / 物理名（camelCase）/ 対象画面 / 概要。
  - 物理名はアクションを表す camelCase（例 `initialize` / `search` / `downloadCsv`）。
  - 対象画面は画面名で記す。

## 固有の決定事項
- 個別の**画面イベント定義書と 1:1** で対応させる。

## 記入例（抽象）

|---|---|---|---|---|
