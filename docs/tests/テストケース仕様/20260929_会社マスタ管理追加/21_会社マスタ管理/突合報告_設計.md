## 2. 列挙と対応付けの方法

### 2.1 列挙の単位

- 表の1行＝1記述。表の行は、No 列（`(自動採番)`）を除き、原文の列順にセルを「 \| 」で区切って転記した（空のセルは空のまま）。セル内の改行はキャッシュの表記（` / `）のまま。
- 備考列・特記事項列は文単位で別の記述とした（行本体の記述は出典欄に「備考列を除く」等と記した）。
- 本文（表以外）は文単位で1記述とした。1行に複数の文がある場合は「第n文」として分けた。
- 図（mermaid）は、メッセージ・Note・遷移の1行を1記述とした。囲んでいる alt/else は出典欄に記した。
- 原文はそのまま引用した。ただしキャッシュ上の太字記号（`**`）は引用から除いた。相互参照のフィールドコード（`⟨REF …⟩`）はキャッシュの表記のまま残した。
- 除外した記述の類型と、適用外として除いた個別の記述は「付記 A」に示す。

### 2.2 対応付けの表記

- 「行 N」: 棚卸し行 N の出典欄が、当該記述（文書＋見出し・表の行）を挙げている。
- 「推測: 行 N」: 棚卸し行 N の出典欄は当該記述を挙げていないが、導出単位欄（または出典欄の括弧書き等）の内容との照合で対応付けた。解釈を含む。
- 「※」以下: 記述の一部（文・セル）について、それを扱う行が見当たらない旨の事実。
- 対象外の行（行 115〜行 130）への対応付けも「対応あり」として扱った。

### 2.3 転記/推測の区分

- 転記: 原文引用は原文どおりで、対応付けはすべて棚卸し行の出典欄の記載による（または対応行が無いことの確認）。
- 推測: 原文引用は原文どおりだが、次のいずれかの解釈を含む。括弧内に種類を示す。
  - 導出単位: 対応付けの一部または全部が導出単位欄との照合による。
  - 括弧書き: 出典欄の括弧書き（パス・メソッドの表記）との照合による。
  - 位置: 出典欄は同じ文書の同じ見出し・表を挙げるが、引用・指示している文・表が当該記述とは別。
  - 概要: 共通仕様の概要行（本紙の適用を定める記述）を、その共通仕様を出典に含む行と照合した。
  - 適用: 原文が本画面を名指ししておらず、本画面に適用される記述として選んだこと自体に解釈を含む。
