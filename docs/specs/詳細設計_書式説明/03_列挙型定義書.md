# 列挙型定義書 記載規範

> 共通規範は [00_共通規範.md](00_共通規範.md) を参照。本書は本様式固有の事項のみ記す。

## 役割
列挙型（状態区分・定数の集合）**1件**の定義。

## 配置・ファイル名
`型情報定義書/列挙型/<論理名>_列挙型定義書.docx`（凡例に合わせ `列挙型/` 配下。`<論理名>` は基本設計の論理名。物理名（PascalCase）は本文・一覧表で定義する）。

## ヘッダー固有
- 機能グループ：`―`（横断型）。
- 機能：`型情報定義 / <論理名>`（2段落）。
- 文書種別名：`型情報定義書 列挙型`。

## 本文の構成と書き方
- **型定義基本情報**：種別＝`列挙型(定数)`／論理名／物理名（PascalCase）／概要。
- **型定義詳細仕様**：No(自動採番) / 定数論理名 / 定数物理名（コード）/ 型。
  - 型は基本的に `string`（コード値を文字列で表す）。

## 固有の決定事項
- **区分値の正本は基本設計のエンティティ定義書**。取りうる値をそのまま漏れなく列挙する。
- 定数物理名は**コード値**であり、これを永続化列（テーブル定義書）にも文字列として保持する。

## 記入例（抽象）
| 定数論理名 | 定数物理名 | 型     |
| ---------- | ---------- | ------ |
| オープン   | OPEN       | string |
| クローズ   | CLOSED     | string |
