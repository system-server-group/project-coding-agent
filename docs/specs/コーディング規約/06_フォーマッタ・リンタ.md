# フォーマッタ・リンタの実装規範

> 共通規範は [00_実装共通規範.md](00_実装共通規範.md) を参照。
> IDE 連携の設定手順・Checkstyle ルールの方針は [ide-setup.md](../../ide-setup.md) を参照。

## 必須要件
- コードを実装・修正したら、**Spotless で整形し、Checkstyle に適合させる**。以下がすべて通過することを実装完了の条件とする。
  - 整形の適用：`./gradlew spotlessApply`
  - 整形の検査：`./gradlew spotlessCheck`
  - 静的解析：`./gradlew checkstyleMain checkstyleTest`
- 未整形・未適合のコードをコミットしない。ビルド・テストの通過だけをもって完了としない。

## 違反への対処
- Checkstyle 違反は自動修正されない。指摘に従って**手で直す**。
- 抑制（`@SuppressWarnings` 相当の除外・設定の緩和）で違反を黙らせない。ルール自体の見直しが必要と判断した場合は、勝手に変更せずユーザーに確認する。

## 設定の正本
- 整形規則：`config/eclipse/eclipse-formatter.xml`（Spotless `eclipse()` と IDE が共用）
- 静的解析規則：`config/checkstyle/checkstyle.xml`（Gradle `checkstyle` と IDE プラグインが共用）
- Checkstyle のバージョンは `build.gradle.kts` の `toolVersion` が正本。IDE 側の設定はこれに合わせる。
